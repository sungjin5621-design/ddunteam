뚠뚠팀 v37.2 FINAL 배포 안내

이번 버전은 기존 데이터를 초기화하지 않고, v36/v37에서 발생한 UI/정렬/데이터 보존 문제를 안정화한 최종 패치입니다.

반영 내용
1. 메인 캘린더에서 일정 미리보기/시간 라벨 제거. 공휴일은 유지.
2. 페이지 소유자(베키)에게 상단 '✎ 수정' 버튼 강제 복구.
3. 마음의 편지함 저장키를 v35 기준으로 복구하고 v33/v34/기존 키 데이터를 자동 이관. 기존 데이터가 있으면 덮어쓰지 않음.
4. 혈맹원 목록과 인원 관리 정렬 통일: 등급 → 레벨 내림차순 → 랭킹 오름차순 → 랭킹 없음 → 닉네임 가나다순.
5. 인원 관리에서 #랭킹 뱃지는 표시하지 않음.
6. 혈맹원 편집창에서 랭킹 순위 입력/저장 복구.
7. 로그인 비밀번호 규칙 복구: 베키 5621 / 군주·관리자·수호 12161216 / 일반 1216.
8. 뚠뚠 메모장 분배금 UI 폭/overflow 수정. 데스크톱 2열, 좁은 화면 1열.
9. 분배금 지급 상태/메모/시간분류 DB 기능은 v37.1 SQL과 연동.

배포 순서
A. Supabase SQL Editor에서 supabase_distribution_v37_1_fix.sql 전체 실행
B. SQL 실행 결과가 Success인지 확인
C. GitHub의 index.html을 이번 ZIP의 index.html로 교체 후 main 브랜치에 업로드
D. Vercel 자동 배포 완료 후 Ctrl+F5

중요
- 기존 데이터 삭제용 SQL은 포함하지 않았습니다.
- 분배금 DB 오류가 계속되면 Supabase SQL Editor에서 아래를 한 번 실행하세요:

- 이번 버전은 기존 localStorage 편지 데이터를 가능한 경우 자동 복구합니다.
