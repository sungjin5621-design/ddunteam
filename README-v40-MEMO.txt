뚠뚠팀 v40 메모장 기능 추가

기준: v39 LIVE STABLE / v36.53 안정 기능 유지

추가된 기능
- 뚠뚠 메모장 분배금 목록: 지급완료/미지급 상태 표시
- 지급/지급취소 버튼
- 혈맹원별 특이사항 메모 버튼 및 저장
- 랭킹순/기본순/레벨순/가나다순 정렬 버튼
- 랭킹순 기본 적용
- 분배금/지급상태/특이사항은 기존 Supabase 분배금 테이블이 있으면 서버 저장
- 서버 연결이 잠시 실패해도 브라우저 임시 저장을 유지

배포
1. index.html을 기존 GitHub index.html과 교체
2. 기존 v39 SQL을 이미 실행했다면 SQL 재실행 불필요
3. Vercel 배포 후 Ctrl+F5

주의
- 기존 DB 데이터를 삭제하거나 초기화하지 않습니다.
- 기존 v39 분배금 테이블을 그대로 사용합니다.
- 신규 SQL이 필요하지 않은 변경입니다.
