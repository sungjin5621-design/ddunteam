뚠뚠팀 v39 LIVE FIX

이번 버전은 v38에서 새 구조를 덧씌워 기존 기능이 깨진 문제를 피하기 위해
마지막 안정 버전(v36.53)을 기준으로 복구했습니다.

복구/유지
- 권한 계층 및 관리자 센터
- 베키의 ✎ 수정 / ⚙ 관리자 버튼
- 마음의 편지함
- 인원 관리 정렬/랭킹
- 혈맹원 목록 및 1인 서버 설정 버튼
- 뚠뚠 메모장 / 운영 메모 히스토리 / 시간 분류
- 보유 혈맹 리스트
- 기존 미니게임/기존 메뉴
- 캘린더 본문 미리보기 제거 상태

추가
- 분배금 지급완료/미지급 상태
- 지급 시간/지급자/특이사항 서버 저장
- 분배금 UI overflow 방지
- v38에서 만들어진 clan_private_state / clan_letters 데이터가 있으면
  로컬 데이터가 비어 있을 때 자동 복구

배포 순서
1. Supabase SQL Editor에서 supabase_v39_LIVE_FIX.sql 전체 실행
2. GitHub main의 index.html을 이 ZIP의 index.html로 교체
3. Vercel 배포 완료 후 Ctrl+F5

주의
- DROP/TRUNCATE/DELETE로 기존 운영 데이터를 지우는 SQL은 없습니다.
- v37/v38의 분배금 테이블이 이미 존재하면 그대로 재사용합니다.
- 기존 v36.53 로컬 저장 데이터가 있으면 그대로 유지합니다.
